# Code of Conduct

This project follows the [Salesforce Open Source Code of Conduct](https://github.com/salesforce/.github/blob/main/CODE_OF_CONDUCT.md).

Please read it before participating. Maintainers will enforce these standards and may remove, edit, or reject contributions that do not comply.

## Reporting Issues

To report a code of conduct violation, contact the maintainers listed in [README.md](README.md) or use the GitHub Issue tracker.
